README

In order to build the tables in this database we used the PGADMIN GUI
so we do not have a create.sql file. We generated our data using both generative AI (ChatGPT) in order to quickly generate csv files with the correct formatting and thousands of entries. We also used Excel macros to manually enter the statistics data as we felt this provided a better experience for our database. We loaded the data using the import csv functionality in the PGADMIN GUI so we have not created a
load file.
